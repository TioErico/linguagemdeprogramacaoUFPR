### Como compilar e rodar os programas em C
# Passo 1:
- No repositório do GitHub, abra a aula desejada e clique em "Code" e em seguida em "Baixar ZIP". Depois descompacte a pasta;
# Passo 2:
- Abra o terminal e navegue até a pasta de origem dos programas baixados;
# Passo 3:
- Digite `gcc <nome_do_arquivo.c> -o <nome_do_executavel>` para compilar o código em um programa executável;
# Passo 4:
- Para rodar, digite no terminal: Para Linux `./<nome_do_executavel>` e para Windows `.\<nome_do_executavel>.exe`.
